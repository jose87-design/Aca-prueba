03 / Método CHISPA

Una brújula.
Seis criterios.

Para una clase, un equipo o un proyecto digital: primero el para qué, después la tecnología.

Conocer mi enfoque ↗
C

Criterio

Aclarar el objetivo antes de elegir una herramienta.

H

Humanismo digital

Diseñar alrededor de las personas y su juicio profesional.

I

Implementación

Pasar de una idea a una prueba útil en el contexto real.

S

Seguridad

Definir datos, límites y responsabilidades desde el principio.

P

Productividad

Quitar fricción para dedicar tiempo a lo que aporta valor.

A

Automatización

Conectar tareas cuando el proceso ya está bien entendido.
